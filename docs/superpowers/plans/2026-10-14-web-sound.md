# Web Sound Output Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the app sound through the piano (MIDI), the browser (a sampled grand piano in Web Audio) or both, chosen in a "Sound output" setting.

**Architecture:** A new `src/audio/` module: pure helpers (`samples.ts`, `voices.ts`), a thin Web Audio player (`web-piano.ts`) and a router (`sound-output.ts`). Controllers stop calling `connection.send` and send every note to a `SoundSink`; `SoundOutput` forwards to the piano and/or the browser piano, and echoes the keys and sustain pedal played on the FP-10 in the browser when it is a target. `midi-io` learns to decode the sustain pedal (CC 64).

**Tech Stack:** Vite 8, Svelte 5, TypeScript 6, Vitest 5 (node environment), Web Audio API, `vite-plugin-pwa` (Workbox precache), ffmpeg + curl (one-off sample preparation script).

**Spec:** `docs/superpowers/specs/2026-10-14-web-sound-design.md`

## Global Constraints

- Setting `soundOutput: 'piano' | 'web' | 'both'`, default `'piano'` (today's behaviour).
- With `'piano'`, no sample is downloaded or decoded and nothing changes for the user, except that on-screen / PC-keyboard notes in the Play screen now sound (spec 2, "Teclado táctil en Tocar").
- Keys played on the FP-10 always sound on the FP-10 (the app never touches Local Control); when the output includes the browser they also sound there, sustain pedal included.
- Samples: Salamander Grand Piano V3 (Alexander Holm, CC BY 3.0), Tone.js MP3s, 30 pitches A0–C8 every minor third, prepared to mono, 8 s, 1.5 s fade-out, 64 kbps, committed in `public/samples/piano/`.
- An app `allNotesOff` never cuts the player's (FP-10) voices in the browser.
- Polyphony limit 48 voices; release time constant 0.1 s (stop after 1 s); cut time constant 0.015 s (stop after 0.1 s); master gain 0.8.
- `AudioContext({ latencyHint: 'interactive' })`, resumed on every `pointerdown` / `keydown` (capture) and when the app becomes visible.
- Every user-visible string comes from `src/i18n` (`en` and `es` with the same keys and placeholders).
- No browser dialogs; no new runtime npm dependencies.
- Each task ends with `npm test` and `npm run check` green and one commit whose message ends with the line `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Stage only your own files (`pnpm-lock.yaml` stays untracked).

```ts
/** Note on/off and sustain pedal (CC 64) from raw MIDI bytes; anything else (other CC, clock…) is null. */
export function decodeMidiMessage(data: ArrayLike<number>, timeMs: number): MidiInputEvent | null {
  if (data.length < 3) return null;
  const type = data[0] & 0xf0;
  if (type === 0x90 && data[2] > 0) {
    return { type: 'on', pitch: data[1], velocity: data[2] / 127, timeMs };
  }
  if (type === 0x80 || type === 0x90) {
    return { type: 'off', pitch: data[1], velocity: 0, timeMs };
  }
  if (type === 0xb0 && data[1] === 64) {
    return { type: 'pedal', down: data[2] >= 64, timeMs };
  }
  return null;
}
```

```ts
const NOTE_FILE_NAMES = ['C', 'Cs', 'D', 'Ds', 'E', 'F', 'Fs', 'G', 'Gs', 'A', 'As', 'B'];

/** A0 */
export const LOWEST_SAMPLE = 21;
/** C8 */
export const HIGHEST_SAMPLE = 108;
const SAMPLE_STEP = 3;

/** Recorded pitches: every minor third from A0 to C8 (A, C, D♯, F♯). */
export const SAMPLE_PITCHES: readonly number[] = Array.from(
  { length: (HIGHEST_SAMPLE - LOWEST_SAMPLE) / SAMPLE_STEP + 1 },
  (_, i) => LOWEST_SAMPLE + i * SAMPLE_STEP,
);

/** File name of a recorded pitch, as Tone.js publishes them: 'A0', 'C1', 'Ds1', 'Fs1'… */
export function sampleName(pitch: number): string {
  return `${NOTE_FILE_NAMES[pitch % 12]}${Math.floor(pitch / 12) - 1}`;
}

/** The recorded pitch closest to `pitch` (at most a semitone away) and the rate that retunes it. */
export function nearestSample(pitch: number): { samplePitch: number; playbackRate: number } {
  const clamped = Math.min(HIGHEST_SAMPLE, Math.max(LOWEST_SAMPLE, Math.round(pitch)));
  const samplePitch = LOWEST_SAMPLE + Math.round((clamped - LOWEST_SAMPLE) / SAMPLE_STEP) * SAMPLE_STEP;
  return { samplePitch, playbackRate: 2 ** ((clamped - samplePitch) / 12) };
}

const clamp01 = (v: number) => Math.min(1, Math.max(0, v));

/** Loudness of a note struck at `velocity` (0–1). */
export function velocityGain(velocity: number): number {
  const v = clamp01(velocity);
  return 0.05 + 0.95 * v * v;
}

/** Low-pass cutoff in Hz: the samples have one dynamic layer, so soft notes are darkened. */
export function velocityCutoff(velocity: number): number {
  return 1500 * (16000 / 1500) ** clamp01(velocity);
}
```

```ts
/** Who started a voice: the app (auto-play, previews, on-screen keys) or the pianist on the piano. */
export type VoiceSource = 'app' | 'player';

export const MAX_VOICES = 48;

interface Entry<V> {
  voice: V;
  source: VoiceSource;
  pitch: number;
}

/**
 * Which voices are sounding, for whom and why. No audio here: every method
 * returns the voices the caller has to cut or fade out.
 */
export class VoiceBook<V> {
  /** Sounding voices, oldest first. */
  private voices: Entry<V>[] = [];
  private pedalDown = false;
  /** Keys the pianist is holding down. */
  private keysDown = new Set<number>();

  constructor(private readonly maxVoices = MAX_VOICES) {}

  get size(): number {
    return this.voices.length;
  }

  /** Adds a voice; returns the voices to cut: the same key of the same source, and the oldest beyond the limit. */
  start(source: VoiceSource, pitch: number, voice: V): V[] {
    const cut: V[] = [];
    this.voices = this.voices.filter((e) => {
      if (e.source !== source || e.pitch !== pitch) return true;
      cut.push(e.voice);
      return false;
    });
    if (source === 'player') this.keysDown.add(pitch);
    this.voices.push({ voice, source, pitch });
    while (this.voices.length > this.maxVoices) cut.push(this.voices.shift()!.voice);
    return cut;
  }

  /** Key up: the voice to fade out, or null when none is sounding or the sustain pedal holds it. */
  release(source: VoiceSource, pitch: number): V | null {
    if (source === 'player') {
      this.keysDown.delete(pitch);
      if (this.pedalDown) return null;
    }
    const index = this.voices.findIndex((e) => e.source === source && e.pitch === pitch);
    return index < 0 ? null : this.voices.splice(index, 1)[0].voice;
  }

  /** The pianist's sustain pedal; lifting it returns the held voices whose key is already up. */
  setPedal(down: boolean): V[] {
    this.pedalDown = down;
    if (down) return [];
    const released: V[] = [];
    this.voices = this.voices.filter((e) => {
      if (e.source !== 'player' || this.keysDown.has(e.pitch)) return true;
      released.push(e.voice);
      return false;
    });
    return released;
  }

  /** Every voice of `source` (both sources when omitted). Releasing the player's also forgets the pedal and keys. */
  releaseAll(source?: VoiceSource): V[] {
    if (source !== 'app') {
      this.pedalDown = false;
      this.keysDown.clear();
    }
    const released: V[] = [];
    this.voices = this.voices.filter((e) => {
      if (source !== undefined && e.source !== source) return true;
      released.push(e.voice);
      return false;
    });
    return released;
  }

  /** A voice that finished playing by itself. */
  ended(voice: V): void {
    const index = this.voices.findIndex((e) => e.voice === voice);
    if (index >= 0) this.voices.splice(index, 1);
  }
}
```

```ts
import { SAMPLE_PITCHES, nearestSample, sampleName, velocityCutoff, velocityGain } from './samples';
import { VoiceBook, type VoiceSource } from './voices';

export type WebPianoStatus = 'idle' | 'loading' | 'ready' | 'error';

export interface WebPianoDeps {
  createContext?: () => AudioContext;
  fetchSample?: (name: string) => Promise<ArrayBuffer>;
}

interface Voice {
  node: AudioBufferSourceNode;
  gain: GainNode;
}

interface Fade {
  /** Seconds for the level to fall by ~63 %. */
  timeConstant: number;
  /** Seconds until the voice is stopped. */
  stopAfter: number;
}

const MASTER_GAIN = 0.8;
/** A key let go: the damper stops the string. */
const RELEASE: Fade = { timeConstant: 0.1, stopAfter: 1 };
/** A voice cut to make room (same key again, or too many voices). */
const CUT: Fade = { timeConstant: 0.015, stopAfter: 0.1 };

function defaultCreateContext(): AudioContext {
  return new AudioContext({ latencyHint: 'interactive' });
}

async function defaultFetchSample(name: string): Promise<ArrayBuffer> {
  const response = await fetch(new URL(`samples/piano/${name}.mp3`, document.baseURI));
  if (!response.ok) throw new Error(`${name}: HTTP ${response.status}`);
  return response.arrayBuffer();
}

/** Sampled grand piano played through Web Audio. Silent until load() has finished. */
export class WebPiano {
  private ctx: AudioContext | null = null;
  private output: AudioNode | null = null;
  private buffers = new Map<number, AudioBuffer>();
  private readonly book = new VoiceBook<Voice>();
  private state: WebPianoStatus = 'idle';
  private listeners = new Set<(s: WebPianoStatus) => void>();
  private readonly createContext: () => AudioContext;
  private readonly fetchSample: (name: string) => Promise<ArrayBuffer>;

  constructor(deps: WebPianoDeps = {}) {
    this.createContext = deps.createContext ?? defaultCreateContext;
    this.fetchSample = deps.fetchSample ?? defaultFetchSample;
  }

  /** Svelte-store compatible: calls cb now and on every change. */
  subscribe(cb: (s: WebPianoStatus) => void): () => void {
    cb(this.state);
    this.listeners.add(cb);
    return () => {
      this.listeners.delete(cb);
    };
  }

  get status(): WebPianoStatus {
    return this.state;
  }

  /** Downloads and decodes the samples. Does nothing while loading or once ready; retries after an error. */
  async load(): Promise<void> {
    if (this.state === 'loading' || this.state === 'ready') return;
    this.setStatus('loading');
    try {
      const ctx = this.ensureContext();
      const decoded = await Promise.all(
        SAMPLE_PITCHES.map(
          async (pitch) => [pitch, await ctx.decodeAudioData(await this.fetchSample(sampleName(pitch)))] as const,
        ),
      );
      this.buffers = new Map(decoded);
      this.setStatus('ready');
    } catch {
      this.setStatus('error');
    }
  }

  /** Browsers keep audio suspended until a user gesture: call from one (and when the app is shown again). */
  resume(): void {
    if (this.ctx?.state === 'suspended') void this.ctx.resume().catch(() => undefined);
  }

  /** `velocity` 0–1. */
  noteOn(source: VoiceSource, pitch: number, velocity: number): void {
    const ctx = this.ctx;
    const output = this.output;
    if (this.state !== 'ready' || !ctx || !output) return;
    const { samplePitch, playbackRate } = nearestSample(pitch);
    const buffer = this.buffers.get(samplePitch);
    if (!buffer) return;
    this.resume();
    const node = ctx.createBufferSource();
    node.buffer = buffer;
    node.playbackRate.value = playbackRate;
    const filter = ctx.createBiquadFilter();
    filter.type = 'lowpass';
    filter.frequency.value = velocityCutoff(velocity);
    const gain = ctx.createGain();
    gain.gain.value = velocityGain(velocity);
    node.connect(filter).connect(gain).connect(output);
    const voice: Voice = { node, gain };
    node.onended = () => {
      this.book.ended(voice);
      gain.disconnect();
    };
    node.start(ctx.currentTime);
    for (const old of this.book.start(source, pitch, voice)) this.fade(old, CUT);
  }

  noteOff(source: VoiceSource, pitch: number): void {
    const voice = this.book.release(source, pitch);
    if (voice) this.fade(voice, RELEASE);
  }

  /** The pianist's sustain pedal. */
  setPedal(down: boolean): void {
    for (const voice of this.book.setPedal(down)) this.fade(voice, RELEASE);
  }

  /** Releases every voice of `source`, or every voice when omitted. */
  allNotesOff(source?: VoiceSource): void {
    for (const voice of this.book.releaseAll(source)) this.fade(voice, RELEASE);
  }

  private ensureContext(): AudioContext {
    if (this.ctx) return this.ctx;
    const ctx = this.createContext();
    const compressor = ctx.createDynamicsCompressor();
    compressor.connect(ctx.destination);
    const master = ctx.createGain();
    master.gain.value = MASTER_GAIN;
    master.connect(compressor);
    this.ctx = ctx;
    this.output = master;
    return ctx;
  }

  private fade(voice: Voice, fade: Fade): void {
    const ctx = this.ctx;
    if (!ctx) return;
    const now = ctx.currentTime;
    voice.gain.gain.cancelScheduledValues(now);
    voice.gain.gain.setTargetAtTime(0, now, fade.timeConstant);
    try {
      voice.node.stop(now + fade.stopAfter);
    } catch {
      // Already stopped.
    }
  }

  private setStatus(status: WebPianoStatus): void {
    this.state = status;
    for (const cb of this.listeners) cb(status);
  }
}
```

```ts
import type { OutputEvent } from '../engine/types';
import type { ConnectionStatus, NoteEvent, PedalEvent } from '../midi-io/types';
import type { VoiceSource } from './voices';

export type SoundTarget = 'piano' | 'web' | 'both';

/** Where the app's own notes go: auto-play, previews and the on-screen / PC keyboard. */
export interface SoundSink {
  send(event: OutputEvent): void;
}

/** What the output needs from the connection to the piano (ConnectionManager). */
export interface PianoLink {
  send(event: OutputEvent): void;
  onNote(cb: (e: NoteEvent) => void): () => void;
  onPedal(cb: (e: PedalEvent) => void): () => void;
  subscribe(cb: (s: ConnectionStatus) => void): () => void;
}

/** What the output needs from the browser piano (WebPiano). */
export interface BrowserPiano {
  load(): Promise<void>;
  noteOn(source: VoiceSource, pitch: number, velocity: number): void;
  noteOff(source: VoiceSource, pitch: number): void;
  setPedal(down: boolean): void;
  allNotesOff(source?: VoiceSource): void;
}

const toPiano = (target: SoundTarget) => target !== 'web';
const toWeb = (target: SoundTarget) => target !== 'piano';

/**
 * Sends the app's sound to the piano (MIDI), the browser piano or both. Keys and
 * pedal played on the piano always sound on the piano itself; when the browser is
 * a target they also sound there.
 */
export class SoundOutput implements SoundSink {
  private current: SoundTarget = 'piano';

  constructor(
    private readonly link: PianoLink,
    private readonly webPiano: BrowserPiano,
  ) {
    link.onNote((e) => {
      if (!toWeb(this.current)) return;
      if (e.type === 'on') webPiano.noteOn('player', e.pitch, e.velocity);
      else webPiano.noteOff('player', e.pitch);
    });
    link.onPedal((e) => {
      if (toWeb(this.current)) webPiano.setPedal(e.down);
    });
    // A dropped link never delivers the note-offs: release what the piano was holding.
    link.subscribe((status) => {
      if (status.state !== 'connected') webPiano.allNotesOff('player');
    });
  }

  get target(): SoundTarget {
    return this.current;
  }

  setTarget(target: SoundTarget): void {
    const previous = this.current;
    if (target === previous) return;
    this.current = target;
    if (toWeb(previous) && !toWeb(target)) this.webPiano.allNotesOff();
    if (toPiano(previous) && !toPiano(target)) this.link.send({ type: 'allNotesOff' });
    if (toWeb(target) && !toWeb(previous)) void this.webPiano.load().catch(() => undefined);
  }

  send(event: OutputEvent): void {
    if (toPiano(this.current)) this.link.send(event);
    if (!toWeb(this.current)) return;
    switch (event.type) {
      case 'noteOn':
        this.webPiano.noteOn('app', event.pitch, event.velocity / 127);
        break;
      case 'noteOff':
        this.webPiano.noteOff('app', event.pitch);
        break;
      case 'allNotesOff':
        this.webPiano.allNotesOff('app');
        break;
    }
  }
}
```

`src/ui/local-notes.ts`:

```ts
/** Counts the on-screen and PC-keyboard sources holding each pitch (two fingers can hold one key). */
export class LocalNotes {
  private counts = new Map<number, number>();

  /** True when this is the first source to hold the pitch. */
  press(pitch: number): boolean {
    const count = this.counts.get(pitch) ?? 0;
    this.counts.set(pitch, count + 1);
    return count === 0;
  }

  /** True when the last source let go of the pitch. */
  release(pitch: number): boolean {
    const count = this.counts.get(pitch) ?? 0;
    if (count === 0) return false;
    if (count === 1) {
      this.counts.delete(pitch);
      return true;
    }
    this.counts.set(pitch, count - 1);
    return false;
  }

  has(pitch: number): boolean {
    return this.counts.has(pitch);
  }
}
```

```ts
    void connection.startUsb($settings.preferredDevice);
    // Browsers keep audio suspended until a user gesture: wake the browser piano on every tap or key.
    const wake = () => webPiano.resume();
    const onVisibility = () => {
      if (document.visibilityState === 'visible') webPiano.resume();
    };
    window.addEventListener('pointerdown', wake, true);
    window.addEventListener('keydown', wake, true);
    document.addEventListener('visibilitychange', onVisibility);
    return () => {
      window.removeEventListener('pointerdown', wake, true);
      window.removeEventListener('keydown', wake, true);
      document.removeEventListener('visibilitychange', onVisibility);
    };
  });
```

- [ ] **Step 1: Write the script**

`scripts/fetch-piano-samples.sh`:

```bash
#!/usr/bin/env bash
# Downloads the Salamander Grand Piano samples published by Tone.js and prepares them
# for the browser piano: mono, 8 s with a 1.5 s fade-out, 64 kbps MP3.
# Needs curl and ffmpeg. Output: public/samples/piano/.
set -euo pipefail
cd "$(dirname "$0")/.."

SOURCE=https://tonejs.github.io/audio/salamander
OUT=public/samples/piano
TMP=$(mktemp -d)
trap 'rm -rf "$TMP"' EXIT
mkdir -p "$OUT"

names="A0"
for octave in 1 2 3 4 5 6 7; do
  names="$names C$octave Ds$octave Fs$octave A$octave"
done
names="$names C8"

for name in $names; do
  curl -fsSL -o "$TMP/$name.mp3" "$SOURCE/$name.mp3"
  ffmpeg -loglevel error -y -i "$TMP/$name.mp3" -ac 1 -t 8 -af "afade=t=out:st=6.5:d=1.5" -b:a 64k "$OUT/$name.mp3"
done
echo "Wrote $(ls "$OUT"/*.mp3 | wc -l) samples to $OUT"
```
